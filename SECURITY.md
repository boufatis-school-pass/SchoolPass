# Security and privacy reporting

SchoolPass may process student records and guardian identity numbers. Do not publish databases, student lists, reports, backups, screenshots containing personal information, or Windows DPAPI material in GitHub issues.

For a security concern, contact the project maintainer privately through the repository owner's verified contact channel. Include the application version and a reproducible description, but remove all personal data.

The daily detailed report contains full guardian identity numbers and is restricted in application logic to the system administrator. Keep generated reports inside the school administration and dispose of unnecessary copies securely.
