SchoolPass 2.5.3 — تقرير الفحوص المحلية

بيئة الفحص: Linux، Python 3.x. لم تُثبت بعض متطلبات تشغيل ملفات PDF والبناء في هذه البيئة.

النتائج:
1) pytest -q -rs — ناجح: 105 اختبارًا، 13 اختبار PDF متخطى، صفر إخفاق.
2) python -m compileall -q app.py schoolpass_core.py test_*.py — ناجح.
3) python audit_arabic_text.py — ناجح؛ ملفات المصدر مقروءة بترميز UTF-8 والمصطلحات الإدارية الأساسية موجودة.
4) python release_preflight.py — ناجح؛ اتساق الإصدار وملفات النشر والأيقونة موجودة ولا توجد قاعدة بيانات أو مخلفات بناء في شجرة المصدر.
5) python preflight.py — لم ينجح محليًا بسبب عدم وجود المكتبات الاختيارية التالية في بيئة الفحص: arabic_reshaper وbidi وxlrd وPyInstaller.

سبب الاختبارات المتخطاة:
الاختبارات الـ13 في test_pdf.py تم تخطيها لأن مكتبتَي arabic_reshaper وpython-bidi غير مثبتتين في بيئة الفحص الحالية؛ وهما مطلوبتان ضمن مسار اختبار طباعة العربية. متطلبات التطوير والبناء موجودة في requirements_dev.txt ويجب تثبيتها في Windows/GitHub Actions قبل البناء.

حدود الفحص:
- لا يثبت اختبار الواجهة الوهمي شكل الواجهة بصريًا أو سلوك DPI الحقيقي.
- لم يُبنَ SchoolPass.exe أو SchoolPass_Setup.exe محليًا؛ البيئة الحالية ليست Windows ولا تتضمن Inno Setup.
- لم تُختبر الطباعة الفعلية على Canon LBP6000B.
- لا يمكن من هذه النتائج الجزم بنجاح GitHub Actions قبل رفع الملفات ودفع الوسم v2.5.3.

الحالة:
حزمة المصدر اجتازت 105 اختبارات وعمليات فحص محلية متاحة، مع 13 اختبارًا متخطى بسبب غياب مكتبات PDF. المثبّت النهائي واختبار التشغيل والطباعة على Windows ما زالت خطوات مطلوبة بعد رفع المصدر إلى المستودع.
