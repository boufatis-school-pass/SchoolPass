SchoolPass 2.5.0 — تقرير الفحوص المحلية
تاريخ التنفيذ: 31-10-2026

نتائج نجحت:
- python -m py_compile app.py schoolpass_core.py
- python audit_arabic_text.py
- python release_preflight.py
- pytest -q -rs: 92 passed, 13 skipped, 0 failed.
- اختبار التقرير اليومي: حقول الولي، رقم الهوية الكامل، تاريخ بداية الغياب وطريقة التبرير.
- اختبار صلاحية المدير للتقرير اليومي.
- اختبار مقارنة أرقام الإصدارات في فاحص تحديثات GitHub.
- اختبار ثبات دالة رسم رخصة الخروج المعتمدة عبر بصمة AST.

سبب الاختبارات المتجاوزة:
- 13 اختبار PDF متجاوزة لأن مكتبتَي arabic-reshaper وpython-bidi غير متاحتين في بيئة التطوير الحالية. هاتان المكتبتان مذكورتان ضمن requirements.txt ويفترض تثبيتهما أثناء بناء Windows؛ يجب التأكد من نجاح هذه الاختبارات على بيئة البناء.

ما لم يُختبر في هذه البيئة:
- لم يتم بناء SchoolPass.exe أو SchoolPass_Setup.exe؛ البيئة الحالية ليست Windows ولا تحتوي PowerShell أو Inno Setup.
- لم يتم اختبار DPAPI على حساب Windows حقيقي.
- لم يتم فتح واجهة البرنامج بصريًا على Windows أو اختبار نسب DPI المختلفة.
- لم يتم اختبار التثبيت والتحديث فوق نسخة موجودة فعليًا.
- لم تتم الطباعة على Canon LBP6000B أو التحقق من أبعاد الورق فعليًا.

الخلاصة:
اجتاز المصدر والاختبارات المتاحة الفحوص المحلية دون فشل. الحزمة هي مستودع مصدر 2.5.0 جاهز للرفع والبناء، وليست ملف تثبيت Windows معتمدًا. يجب استكمال قائمة اختبار ما قبل الاعتماد على جهاز المؤسسة قبل إدخال بيانات التلاميذ الأصلية.
