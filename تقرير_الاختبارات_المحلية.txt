SchoolPass 2.5.1 — تقرير الفحوص المحلية

بيئة الفحص: Linux، Python 3.x، لا تتضمن مكتبات التطبيق/البناء الاختيارية كاملة.

النتائج:
1) python -m compileall -q app.py schoolpass_core.py test_ui_smoke.py — ناجح.
2) python audit_arabic_text.py — ناجح؛ ملفات المصدر UTF-8 والمصطلحات الإدارية الأساسية موجودة.
3) python release_preflight.py — ناجح؛ أرقام الإصدار متطابقة وملفات النشر المطلوبة موجودة ولا توجد قاعدة بيانات أو مخلفات بناء داخل المصدر.
4) python -m pytest -q -rs — 94 ناجحًا، 13 اختبارًا متخطى، صفر إخفاق.

سبب الاختبارات المتخطاة:
الاختبارات الـ13 في test_pdf.py لم تُنفذ لأن مكتبات PDF غير مثبتة في بيئة الفحص الحالية. ملف requirements_dev.txt يتضمن متطلبات البناء والاختبار، ويقوم مسار GitHub Actions بتثبيتها قبل البناء.

حدود الفحص:
- فشل preflight.py محليًا بسبب غياب arabic_reshaper وbidi وxlrd وPyInstaller في بيئة الفحص هذه؛ لا يعني ذلك وجود خطأ في المصدر، لكن يجب أن ينجح هذا الفحص على Windows بعد تثبيت requirements_dev.txt في GitHub Actions.
- لم يُبنَ SchoolPass.exe أو SchoolPass_Setup.exe محليًا؛ بيئة الفحص ليست Windows ولا تحتوي Inno Setup.
- لم يُختبر العرض المرئي الفعلي أو DPI أو عجلة الماوس على جهاز Windows 10.
- لم تُختبر الطباعة على Canon LBP6000B.

الحكم:
حزمة مصدر 2.5.1 اجتازت فحوص Python الأساسية والاختبارات المتاحة. لا تُعد مثبتًا نهائيًا معتمدًا حتى ينجح GitHub Actions، ثم تُختبر الواجهة والطباعة على Windows باستخدام قاعدة بيانات تجريبية.
